## DMIT 是什么，Eyeball 系列和其他系列有什么区别

DMIT 是一家总部在美国、主要面向亚太用户的 VPS 服务商，机房覆盖香港、日本东京、洛杉矶等地。他们的产品线按网络类型分成几个系列，Eyeball 是其中专门针对"家宽用户访问体验"优化的一档。

具体来说，Eyeball 系列的回程路由会优先走 CN2 GIA 或者直连骨干，而不是绕道走普通 Transit。对于国内用户来说，这意味着晚高峰的延迟和丢包表现会比普通 Premium 带宽套餐稳定不少。

DMIT 的另外两个主要系列是 Premium（纯 CN2 GIA 双向，价格更高）和 Lite（走普通带宽，价格便宜但高峰期表现一般）。Eyeball 夹在中间——回程优化，去程走普通路由，价格比 Premium 低，适合大多数只在意"国内访问速度"的用户。

我自己的用法是把它当跳板机和轻量 Web 服务器，不跑大流量任务，Eyeball 完全够用。

## 香港节点 vs 日本节点：我的实际使用感受

这两个节点我都用过，选哪个主要看你的使用场景。

**香港节点**的优势是对国内大部分地区延迟最低，尤其是华南、华东用户，晚高峰延迟通常在 30–50ms 区间。我在上海用联通宽带测过，工作日晚上 9 点到 11 点这段时间，ping 值基本稳定，没有出现过明显的波动峰值。跑 SSH 操作和轻量 HTTP 服务完全没有感知延迟。

**日本东京节点**的延迟比香港略高一点，华东用户大概在 50–80ms，但胜在带宽资源相对宽裕，跑一些需要稳定吞吐量的任务表现更平稳。另外如果你有访问日本本地资源的需求，东京节点的出口 IP 归属更干净。

两个节点都支持 IPv4 + IPv6 双栈，KVM 虚拟化，可以自己挂载 ISO 重装系统。控制面板是 DMIT 自研的，功能不算花哨，但重启、重装、查流量这些基本操作都有，够用。

一个小细节：DMIT 的 Eyeball 套餐流量是单向计费还是双向，不同套餐可能有差异，下单前建议在官网套餐详情页确认清楚。

## 常见问题

### DMIT Eyeball 和 Premium 系列有什么本质区别？

Eyeball 是回程优化（国内用户访问你的服务器走优质线路），去程走普通路由。Premium 是双向都走 CN2 GIA 或同等级别的优质线路。价格差距通常在 30%–50% 之间。对于大多数建站和轻量服务场景，Eyeball 已经足够；只有对去程延迟也有严格要求的场景才需要 Premium。

### DMIT 的服务器支持哪些操作系统？

官方支持 Debian、Ubuntu、CentOS、AlmaLinux 等主流 Linux 发行版，也支持自定义 ISO 挂载安装其他系统。控制面板里可以直接一键重装，操作比较简单。

### 流量超额之后会怎样？

Eyeball 套餐流量耗尽后会进入限速模式，服务不会中断，但带宽会被限制到一个较低水平。如果你的业务对带宽有持续需求，建议选流量更大的套餐或者在月底前手动升配。

### DMIT 有没有退款保障？

DMIT 官方提供退款政策，具体条款以官网服务协议为准。购买前建议在官网确认当前有效的退款条件，不同套餐和付款周期可能有差异。

### 香港节点适合哪些地区的用户？

华南（广东、广西、福建）和华东（上海、江苏、浙江）用户延迟最低，体验最好。华北用户（北京、天津）延迟会略高一些，但通常也在可接受范围内。西部地区用户建议先测试再购买。

### DMIT 的控制面板好不好用？

功能偏基础，没有 cPanel 那种复杂的图形界面。日常用到的重启、重装、查看流量、管理 SSH Key 这些操作都有，对有一定 Linux 基础的用户来说够用。不适合完全没有服务器操作经验的新手。

### 可以用 DMIT Eyeball 搭建网站吗？

完全可以。Nginx、Apache、Cady 这些 Web 服务器都能正常跑，数据库也没有限制。Mini 套餐（2GB 内存）跑一个中小型 WordPress 站点或者静态站点生成器没有问题，流量不大的情况下 Starter 也够用。
